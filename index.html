力学 › 质点运动

1.1 抛体运动 Projectile Motion

把抛体运动分解成水平匀速与竖直匀加速两个独立运动：x = v₀cosθ·t，y = v₀sinθ·t − ½gt²。 合成一条抛物线；加空气阻力后射程变短。拖动滑块看轨迹、射程、最大高度如何变化。

实时物理量

射程 R–
最大高度 H–
飞行时间 T–

45° 时射程最大；θ 与 (90°−θ) 的射程相同。

公式

射程 R = v₀²sin2θ/g；最大高度 H = v₀²sin²θ/(2g)；飞行时间 T = 2v₀sinθ/g

力学 › 振动

1.2 简谐振动 Simple Harmonic Motion

简谐振动是「匀速圆周运动在一条直径上的投影」。旋转矢量绕圆心匀速转动， 其末端在 x 轴上的投影按 x = A cos(ωt+φ) 来回运动 —— 振幅 A、角频率 ω、相位 φ 三个量完全确定振动。

实时物理量

位移 x–
速度 v–
周期 T = 2π/ω–
机械能 E = ½kA²–

相位差 90° 时位移与速度相差四分之一周期；能量与振幅平方成正比。

公式

x = A cos(ωt+φ)，v = −Aω sin(ωt+φ)，T = 2π/ω

力学 › 振动

1.3 阻尼振动与受迫共振 Damped & Forced

真实振动总有阻尼，振幅按 e−γt/2 衰减。若施加周期性外力，稳态振幅 A(ω) 在共振频率处达到极大，阻尼越小峰越高越尖锐。左图 A(ω) 曲线，右图阻尼振动的时域衰减。

实时物理量

受迫振幅 A(ω)–
共振频率 ω_res–
品质因数 Q–

Q = ω₀/γ 越大共振峰越尖锐；γ ≥ 2ω₀ 时不再振荡（过阻尼）。

公式

A(ω) = (F₀/m)/√((ω₀²−ω²)² + γ²ω²)，ω_res = √(ω₀²−γ²/2)，Q = ω₀/γ

力学 › 波动

1.4 机械波：行波、驻波与拍 Traveling / Standing Wave

行波 y = A cos(kx−ωt) 沿 x 传播；两列反向行波叠加成驻波（节点不动、波腹振幅最大）； 两列频率接近的波叠加产生拍。切换模式观察。

实时物理量

波长 λ = 2L/n–
频率 f = nv/2L–
节点数–

驻波节点等间距 L/n，是「边界条件导致量子化」的先声。

公式

驻波 λ_n = 2L/n，f_n = nv/(2L)；拍频 Δf = |f₁−f₂|

力学 › 波动

1.5 多普勒效应 Doppler Effect

波源在介质中运动时，前方波前被压缩、后方被拉伸，观察者接收到的频率 f′ = f·v/(v−v_s)。救护车驶近时音调升高、驶离时降低，就是这个效应。

实时物理量

观测频率 f′–
频率比 f′/f–

波源速度越接近波速，前方波前越密集；v_s = v 时前方波前堆叠成冲击波。

公式

f′ = f·v/(v−v_s)（源靠近）；f′ = f·v/(v+v_s)（源远离）

力学 › 动量

1.6 碰撞与动量守恒 Momentum Conservation

两物体碰撞时，若无外力，总动量守恒。弹性碰撞动能也守恒（等质量球弹性碰撞会交换速度）， 完全非弹性碰撞后两球粘在一起。切换模式看碰撞后的速度。

实时物理量

碰撞后 v₁′–
碰撞后 v₂′–
总动量 p–
总动能 KE–

弹性碰撞动量、动能双守恒；完全非弹性碰撞动能损失最大。

公式

弹性 v₁′ = ((m₁−m₂)v₁+2m₂v₂)/(m₁+m₂)；完全非弹性 v′ = (m₁v₁+m₂v₂)/(m₁+m₂)

热学 › 分子动理论

2.1 理想气体（微观模型） Ideal Gas

理想气体是一大群作无规则热运动、相互间几乎不碰撞的分子。温度越高分子平均动能越大、 撞击器壁越剧烈，压强越大：p = (1/3)nmv̄² = nkT。左图为分子运动的微观示意。

实时物理量

压强 p = nkT–
方均根速率 v_rms–
平均平动动能–

公式

p = n k T，v_rms = √(3kT/m)，平均平动动能 (3/2)kT

热学 › 热力学

2.2 热力学第一定律 First Law

第一定律 Q = ΔU + W：系统吸热一部分增加内能、一部分对外做功。 四个典型过程（等温、绝热、等压、等容）在 p–V 图上路径不同，曲线下面积就是功 W。

实时物理量

做功 W–
内能变化 ΔU–
吸热 Q–
第一定律校验–

绝热 Q=0 → ΔU=−W；等容 W=0 → Q=ΔU。

公式

Q = ΔU + W；W = ∫p dV；ΔU = (f/2)nRΔT

热学 › 热力学

2.3 卡诺循环与熵 Carnot Cycle

卡诺循环由两条等温线 + 两条绝热线组成，是两热源之间效率最高的循环： η = 1 − T_c/T_h。效率只与两热源温度有关，与工作物质无关。

实时物理量

卡诺效率 η–
净功 W–

T_c 越低、T_h 越高效率越高，但 T_c 不能低于环境温度。

公式

η = 1 − T_c/T_h；Q_c/Q_h = T_c/T_h；ΔS = Q/T

热学 › 统计分布

2.4 麦克斯韦速率分布 Maxwell Distribution

大量分子速率各不相同，但遵循确定的分布 f(v) = 4π(m/2πkT)^{3/2} v²e^{−mv²/2kT}。 三个特征速率：最概然 v_p < 平均 v̄ < 方均根 v_rms。温度升高，分布展宽、峰值右移。

实时物理量

最概然速率 v_p–
平均速率 v̄–
方均根速率 v_rms–

分子越轻、温度越高，速率越大；三条速率标记在曲线上。

公式

f(v) = 4π(m/2πkT)^{3/2} v² e^{−mv²/2kT}；v_p=√(2kT/m)，v̄=√(8kT/πm)，v_rms=√(3kT/m)

热学 › 统计分布

2.5 能量均分定理 Equipartition

在温度 T 下，分子每个自由度平均分摊 (1/2)kT 的能量。单原子（3 个平动自由度）C_V=(3/2)R， 双原子（+2 转动）C_V=(5/2)R，比热容比 γ=(f+2)/f。左图为不同自由度的能量分配。

1 mol 内能 U–

C_V = (f/2)R，C_p = C_V+R，γ = (f+2)/f，U = (f/2)nRT

电磁学 › 静电场

3.1 库仑定律与电场 Coulomb · E-field

库仑定律 F = kq₁q₂/r² 描述电荷间的力；引入「电场」后，某点场强 E = F/q = kq/r²。 电场线从正电荷出发终止于负电荷，处处垂直于等势面。

实时物理量

场强 E–
电势 V–

场线越密场越强；沿场线方向电势降低。

公式

点电荷 E = kq/r²，V = kq/r；平行板 E = σ/ε₀

电磁学 › 静电场

3.2 高斯定理 Gauss's Law

高斯定理 ∮E·dA = Q_enc/ε₀：闭合曲面的电通量只由内部电荷决定。 对点电荷、无限长线、无限大平面、均匀带电球，选合适的对称高斯面即可一步求出 E。

实时物理量

场强 E(r)–
电通量 Φ = Q/ε₀–

E ∝ 1/r²（球/点）、1/r（线）、常数（平面）—— 对称性决定 E 的衰减规律。

公式

∮E·dA = Q_enc/ε₀；线 E=λ/2πε₀r；面 E=σ/2ε₀

电磁学 › 静电场

3.3 电势与电场梯度 Electric Potential

电势 V 是标量，叠加比矢量方便得多。电场是电势的负梯度：E = −dV/dx。 左图画出点电荷的 V(r) 曲线与 E(r) 曲线，看两者如何对应（E 是 V 的斜率）。

实时物理量

r=1m 处 E–
r=1m 处 V–

V ∝ 1/r，E ∝ 1/r²；E 随距离衰减更快。

公式

V = kq/r，E = −dV/dr = kq/r²

电磁学 › 稳恒磁场

3.4 毕奥-萨伐尔定律 Biot–Savart

电流元产生的磁场 dB = (μ₀/4π)·Idl×r̂/r²。对长直导线积分得 B = μ₀I/2πr， 圆环中心 B = μ₀I/2R，螺线管内部 B = μ₀nI。磁场线是环绕电流的闭合曲线。

实时物理量

磁感应强度 B–

磁场方向用右手定则判断：拇指沿电流，四指沿磁感线。

公式

导线 B=μ₀I/2πr；圆环 B=μ₀I/2R；螺线管 B=μ₀nI

电磁学 › 稳恒磁场

3.5 洛伦兹力 Lorentz Force

磁场对运动电荷的力 F = qv×B 始终垂直于速度，不做功、不改变速率。 v⊥B 时走圆周（回旋半径 r = mv/qB，回旋频率与速度无关）；有平行分量时走螺旋线。

实时物理量

回旋半径 r–
回旋角频率 ω–
回旋周期 T–

速度越快圆周越大，但绕一圈时间不变 —— 回旋加速器原理。

公式

r = mv/qB，ω = qB/m，T = 2πm/qB

电磁学 › 电磁感应

3.6 电磁感应（法拉第与楞次定律） Faraday · Lenz

穿过回路的磁通量变化产生感应电动势 ε = −dΦ/dt。负号是楞次定律： 感应电流的方向总要反抗磁通量的变化（能量守恒的体现）。磁铁进出线圈时 ε 反向。

实时物理量

感应电动势 ε–
磁通量 Φ–
感应方向–

Φ 最大处变化率为零（ε=0）；Φ 变化最快处 ε 最大。

公式

ε = −dΦ/dt，Φ = B·A·cosθ

电磁学 › 麦克斯韦方程组

3.7 电磁波 Electromagnetic Wave

变化的电场激发磁场、变化的磁场激发电场，两者相互激发形成在真空中以光速 c = 1/√(μ₀ε₀) 传播的横波。E 与 B 相互垂直、同相，且 E = cB。

实时物理量

波长 λ = c/f–
电场幅值 E–
磁场幅值 B–

电磁波是横波：E、B 都垂直于传播方向。

公式

c = 1/√(μ₀ε₀)，E = cB，λ = c/f

光学 › 几何光学

4.1 折射与全反射 Snell · Total Reflection

光从一种介质进入另一种介质时发生折射，n₁sinθ₁ = n₂sinθ₂。 从光密到光疏、入射角超过临界角时发生全反射；入射角等于布儒斯特角时反射光完全偏振。

实时物理量

折射角 θ₂–
布儒斯特角 θ_B–
临界角 θ_c–

光纤、潜水镜的全反射都靠这个临界角。

公式

n₁sinθ₁ = n₂sinθ₂；tanθ_B = n₂/n₁；sinθ_c = n₂/n₁（n₁>n₂）

光学 › 波动光学

4.2 杨氏双缝干涉 Young's Double Slit

两束相干光叠加，光程差 d·sinθ = kλ 处相长（亮纹）、(k+½)λ 处相消（暗纹）， 条纹等间距 Δy = λL/d。这是「光是波」的历史性实验证据。

实时物理量

条纹间距 Δy–
第一暗纹位置–

缝距越小、波长越长，条纹越宽。

公式

I ∝ cos²(πd sinθ/λ)；亮纹 d sinθ = kλ；Δy = λL/d

光学 › 波动光学

4.3 薄膜干涉 Thin Film

光在薄膜上下表面反射后叠加干涉：光程差 2nd（+半波损失）决定明暗。 肥皂泡、油膜的彩色即源于此。等厚干涉的一个例子是牛顿环（同心圆环）。

实时物理量

光程差 2nd–
干涉结果–

公式

光程差 Δ = 2nd cosθ（+半波损失）；相长 Δ = kλ，相消 Δ = (k+½)λ

光学 › 波动光学

4.4 单缝衍射 Single-slit Diffraction

光绕过障碍物传播叫衍射。单缝衍射强度 I ∝ sinc²(πa sinθ/λ)， 第一暗纹在 sinθ = λ/a，中央亮纹最宽最亮。缝越窄衍射越显著。

实时物理量

第一暗纹 sinθ = λ/a–
中央亮纹半角宽–

a → λ 时衍射最显著；a ≫ λ 时光近似直线传播（几何光学极限）。

公式

I ∝ sinc²(πa sinθ/λ)；暗纹 a sinθ = kλ

光学 › 波动光学

4.5 光栅衍射 Diffraction Grating

大量等间距狭缝组成光栅，主极大满足 d·sinθ = kλ。缝越多主极大越窄越亮， 分辨本领 R = kN。光栅是光谱仪的核心元件。

实时物理量

一级衍射角 θ₁–
最高级次 k_max–

d 越小各级分得越开；白光入射时不同波长分到不同角度 → 色散。

公式

d sinθ = kλ；分辨本领 R = kN

光学 › 偏振

4.6 光的偏振 Polarization · Malus

光是横波，电场振动方向垂直传播方向。自然光通过偏振片变成线偏振光， 再经第二片偏振片时强度按马吕斯定律 I = I₀cos²θ 变化，θ=90° 完全消光。

实时物理量

透射强度 I/I₀–

透射强度是电场振幅投影的平方 → cos²θ。

公式

I = I₀cos²θ（马吕斯定律）

近代物理 › 量子

5.1 黑体辐射 Blackbody Radiation

黑体辐射的能量谱只由温度决定。经典理论在短波处发散（紫外灾难）， 普朗克假设能量量子化 ε=hν 才得到正确公式。峰值波长 λ_max = b/T（维恩位移），总辐射 M = σT⁴。

实时物理量

峰值波长 λ_max–
